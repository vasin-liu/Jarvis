<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Entity/concept/source names → slug segments | Untrusted indexed titles may contain path separators, CJK, or punctuation |
| Title/display strings → wikilink alias | Display text crosses into Obsidian link syntax |
| Title strings → YAML frontmatter | Quotes and special chars could break or inject YAML structure |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | slugify / uniquify_slug | high | mitigate | Filter to [a-z0-9-] or e-{hash6}; drop / and \\; per-directory collision suffixes (D-05, D-07); unit tests cjk_name_uses_hash_slug, unsafe_path_chars_stripped |
| T-08-02 | Tampering | wikilink display sanitize | medium | mitigate | Strip/replace pipe and closing-bracket in display only; path stays slug (RESEARCH Pitfall 4) |
| T-08-03 | Tampering | frontmatter title field | medium | mitigate | Escape/replace double quotes in title; fixed key set only — no full YAML parser (D-08) |
| T-08-04 | Denial of Service | hash6 on long names | low | accept | SHA-256 on name bytes; bounded 6-char output; no disk I/O |
| T-08-SC | Tampering | cargo workspace deps | low | accept | sha2/hex already in workspace; RESEARCH Package Legitimacy Audit approved — no new crates.io installs |
