    - retrieve with over-fetch config; walk hits in RRF order; skip hit.source_id == seed_id; HashSet dedupe by source_id — first hit wins snippet via truncate_snippet(hit.text); enrich title/kind via get_source(neighbor_id)?; collect until top_n neighbors

  <action>
    Implement pub async fn related_sources(store: &Store, embedder: &dyn Embedder, source_id: &str, top_n: Option<usize>) -> Result<Vec<RelatedSource>> per locked decisions:

    Parse top_n: if top_n == Some(0) return Ok(vec![]); let top_n = top_n.unwrap_or(5).min(32) (D-04).

    let seed = store.get_source(source_id)? — missing id propagates RetrieveError::Store(NotFound) (D-03 not-found vs empty-list distinction).

    let Some(query) = seed_query(&seed) else { return Ok(vec![]); } — short-circuit before retrieve to avoid EmptyQuery Err (D-03).

    let config = related_retriever_config(top_n); let hits = retrieve(store, embedder, &query, &config).await?;

    Rollup: iterate hits in order; if hit.source_id == source_id continue; if seen_source_ids.insert(hit.source_id.clone()) { let neighbor = store.get_source(&hit.source_id)?; push RelatedSource { source_id, title: neighbor.title, kind: neighbor.kind, snippet: truncate_snippet(&hit.text) }; if out.len() == top_n break; }

    Return Ok(out) even when empty (D-05, D-06 — no score threshold, no weak-affinity gate). Do NOT expose ChunkHit.score. Do NOT filter by SourceKind (D-10, D-11). Do NOT open SQLite outside Store. Sequence: get_source seed → build query → retrieve (embed inside retrieve) — no Store lock held across embed.
