# Phase 13 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase nature:** E2E harness + citation trust (WIKI-08, WIKI-09) — **not** a visual redesign. Product wiki UI shipped in Phases 11–12. This contract locks surgical testability hooks, inherited tokens, and the user-journey interaction sequence E2E must drive.

| Property | Value |
|----------|-------|

| Component library | none — existing React + Tailwind v4 (`src/`) |

**Reuse (mandatory — do not redesign):**
- Settings wiki accordion + toggle (Phase 11) — `settings-section-wiki`, `wiki-enabled-toggle`, labels「Wiki 笔记」/「启用 Wiki 笔记层」

- Export success notice (Phase 12) — AppShell `data-testid="wiki-export-done"` emerald glass panel
- Chat citations — existing cyan link buttons + `citation-excerpt` div
- Persist — existing bottom「保存配置」`btn-primary`

**Phase 13 UI delta (surgical only):**
1. Add `data-source-uri={c.source_uri}` on Chat citation **`<button>`** (D-09) — no class/style change
2. [ASSUMED] Add `data-testid="settings-save-config"` on Settings「保存配置」button — no visual change
3. Honor `__JARVIS_E2E_WIKI_EXPORT_PATH__` in `exportWiki` — invisible to end users (D-05); production Save dialog UX unchanged

## Interaction Contract (E2E-driven UX)

Phase 13 does not add product flows; it **contracts** how existing UI is used and what must remain invisible to users.

| Step | Surface | Behavior |
|------|---------|----------|
| Default-off | Library | When `wiki.enabled !== true`: **no** `wiki-export`, **no** `wiki-compile-*` in DOM (hide, not disable) |
| Enable | Settings | Expand `settings-section-wiki` → check「启用 Wiki 笔记层」→ click「保存配置」→ config persists (D-03 hybrid; do not seed enabled at E2E process start) |
| Compile | Library | First eligible `wiki-compile-*` on non-`wiki_page` indexed row (D-04) |
| Compile success | Library | Silent refresh; ≥1 row shows kind label **笔记页** (D-02) — no compile toast |
| Export (users) | Library | Unchanged: preflight → native Save dialog → zip write → emerald notice |
| Export (E2E only) | `useLibrary.exportWiki` | If `window.__JARVIS_E2E_WIKI_EXPORT_PATH__` set: **skip** `save()`, call `export_wiki_zip(destPath)` — no Save dialog UX change for real users (D-05) |
| Export success | AppShell | Show `wiki-export-done`; E2E also asserts zip exists size > 0 (D-06/D-07) |
| Citation trust | Chat | After wiki on + compiled, ask `What is xyzzy-plugh?`; ≥1 citation button with `data-source-uri` **not** starting with `wiki://` (D-10). Wiki citations may co-appear. |
| Citation click | Chat | Unchanged: opens `source_uri` via existing `openCitation` |

### Visibility matrix (unchanged product rules)

| Control | `wiki.enabled !== true` | `wiki.enabled === true` |
|---------|-------------------------|-------------------------|
| Settings toggle | Visible (unchecked) in accordion | Visible (checked) |
| Library「导出 Wiki」 | Hidden | Visible |
| Library「生成笔记」 | Hidden | Visible on indexed non-`wiki_page` |
| Library「笔记页」rows | May remain if previously compiled | Visible after compile |
| Citation `data-source-uri` | Always present when citations render | Same |
