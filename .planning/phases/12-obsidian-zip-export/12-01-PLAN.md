<interfaces>
Public crate API (RESEARCH / PATTERNS; Discretion locked by planner):

- `pub fn wiki_has_exportable_notes(wiki_root: &Path) -> bool` — true iff any `.md` exists under `sources/`, `entities/`, or `concepts/` (D-10). Root-only `index.md` or missing section dirs → false.
- `pub fn export_wiki_zip(wiki_root: &Path, dest_zip: &Path, wiki_enabled: bool) -> Result<()>` —
  - if `!wiki_enabled` → `Err(InsightsError::WikiDisabled)` and do not create dest
  - if `!wiki_has_exportable_notes(wiki_root)` → `Err(InsightsError::WikiEmpty)` (D-12)
  - walk regular files under `wiki_root` only (do not follow symlinks out of root); skip any path whose first relative component is `.obsidian` (D-15)
  - for each packed file: `strip_prefix(wiki_root)`, require every `Component` is `Normal`, normalize separators to `/`, reject absolute / Prefix / ParentDir
  - always `start_file(".obsidian/app.json", …)` with UTF-8 body exactly `{"legacyEditor":false}` (D-13); never mkdir/write that path under `wiki_root` (D-14)
  - write via temp sibling then rename to `dest_zip` (RESEARCH Pitfall 3); delete temp on error
  - CompressionMethod::Deflated via zip 7.2 `SimpleFileOptions`

Errors:
- Add `InsightsError::WikiEmpty` with Display suitable for FE (`to_string()` at Tauri boundary later) — message may mirror empty copy or a clear English/Chinese phrase; preflight FE uses the locked Chinese string separately (D-09)
- Prefer `Zip(#[from] zip::result::ZipError)` or map zip errors into Io — pick one consistently

Deps (Discretion + RESEARCH; NOT zip 8.x):
- Root `Cargo.toml` `[workspace.dependencies]`: `zip = { version = "7.2", default-features = false, features = ["deflate"] }`
- `crates/insights/Cargo.toml`: `zip = { workspace = true }`
- Package legitimacy: OK (RESEARCH audit) — no human checkpoint

Promote: either move `any_content_md` from wiki.rs tests to public `wiki_has_exportable_notes` in wiki_export (or wiki) and have tests call the public fn — do not diverge D-10 semantics.

Do not add Tauri commands, FE, or `wiki.spec.ts` (Plan 02 / Phase 13).
