    2. Read raw JSON; parse to `serde_json::Value`; peek for a non-empty plaintext `cloud_api_key` (top-level — the legacy flat location).

    4. If a legacy key was found AND not in E2E mode: call `secrets::set_api_key(&key)`, then `save_config(path, &config)` to strip the plaintext copy from disk (Pitfall P2), then set `config.embedding.cloud_api_key = key` (runtime field).
    5. If no legacy key AND not in E2E mode: populate `config.embedding.cloud_api_key = secrets::get_api_key().unwrap_or_default()` (D-06 — no panic).
    6. In E2E mode (D-03): skip ALL keyring calls; leave `cloud_api_key` empty.
