## Interaction Contract

### Accordion Behavior
- **Default expanded**: Providers + Index status sections
- **Collapse/expand**: Click section header to toggle
- **Section order**: Providers → Index → Sync → Lark → Agent basics → Advanced
- **Smooth animation**: 300ms ease-out transition for height changes

### Loading States
- **Busy overlay**: Global AppShell overlay during config saves
- **Button disabled**: Individual buttons disabled during operations
- **Progress indicators**: Index progress bar for rebuild operations

### Error Handling
- **Sync errors**: Inline in 定时同步 accordion section (not global banner)
- **Lark errors**: Inline in Lark section after manual sync attempts
- **Global errors**: AppShell error banner for system-level failures

### Empty States
- **No skills/hooks/plugins**: Helper text with location hints
- **No watch folders**: "未配置监听文件夹" placeholder

## Component Inventory

### AppShell Components
- **AppShell.tsx**: Sidebar navigation + global error banner + busy overlay
- **Sidebar navigation**: nav-btn, nav-btn-active, nav-btn-idle classes
- **Global error banner**: Red warning strip at top of shell
- **Busy overlay**: Semi-transparent backdrop with spinner

### Settings Components
- **SettingsView.tsx**: Main settings container
- **AccordionSection**: Collapsible section with header + content
- **ProviderConfig**: Embedder/Chat provider selection + cloud settings
- **IndexStatus**: Health panel with rebuild buttons
- **SyncConfig**: Scheduled sync toggles + watch folders management
- **LarkConfig**: Connection check + manual sync inputs (collapsed under Advanced)
- **AgentBasics**: Orchestration mode selection
- **AgentCRUD**: Agent create/edit forms (under Advanced)
- **SkillsPanel**: Skills toggle list (under Advanced)
- **HooksPanel**: Hooks toggle list (under Advanced)  
- **PluginsPanel**: Plugins + permissions (under Advanced)

### Form Controls
- **field**: Base input class (rounded-xl, border-white/10, focus:ring-2)
- **btn-primary**: Cyan accent button for primary actions
- **btn-ghost**: Subtle border button for secondary actions
- **glass-panel**: Main settings container with backdrop-filter

## Accessibility

### Motion & Transparency
- **Reduced motion**: Honor `prefers-reduced-motion` for accordion animations
- **Reduced transparency**: Solid zinc-900 fallback for glass panels
- **Focus indicators**: 2px cyan ring on all interactive elements

### Keyboard Navigation
- **Tab order**: Logical flow through accordion sections
- **Enter/Space**: Toggle accordion sections and checkboxes
- **Escape**: Close any open dropdowns or modals

### Screen Readers
- **Section headings**: Proper h3 structure for accordion headers
- **Form labels**: All inputs have associated labels
- **Status announcements**: Live regions for sync status updates
- **WCAG AA**: Minimum 4.5:1 contrast ratio on all text
