# Phase 07 — UI Design Contract

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | inherit existing Jarvis tokens / N/A for Phase 07 | inherit (400) | inherit (~1.5) |
| Label | inherit existing Jarvis tokens / N/A for Phase 07 — same as other `sourceKindLabel` strings (e.g.「记忆」「本地文件」) | inherit (400) | inherit |
| Heading | inherit existing Jarvis tokens / N/A for Phase 07 | inherit (600) | inherit (~1.2) |
| Display | inherit existing Jarvis tokens / N/A for Phase 07 | inherit | inherit |

**Phase 07 typography rule:** The wiki kind label uses the **identical** text styling as existing kind labels in Library (no new size/weight/color). Do not style「笔记页」differently from「记忆」.

Declared sizes/weights for checker (inherited product defaults, not new tokens): **3 roles used in app** — body ~14px (`text-sm`), label ~14px, heading ~16–20px; **2 weights** — regular (400) + medium/semibold (500–600) via existing Tailwind utilities. Phase 07 introduces **zero** new type tokens.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | inherit existing Jarvis — `zinc-950` / dark surfaces | Background, surfaces — N/A change this phase |
| Secondary (30%) | inherit existing Jarvis — `zinc-900/55` glass panels | Cards, sidebar, nav — N/A change this phase |
| Accent (10%) | inherit existing Jarvis — cyan (`cyan-400` / `cyan-500`) | Reserved for existing CTAs, nav active, progress — **not** for wiki label |
| Destructive | inherit existing Jarvis — existing error/status-err tones | Destructive actions only — N/A this phase |

Accent reserved for: primary buttons (`.btn-primary`), active nav (`.nav-btn-active`), stream cursor, index progress fill — **never** for the wiki kind label string.

**Phase 07 color rule:**「笔记页」inherits the same foreground color as other kind labels (typically `text-zinc-*` muted/secondary text in Library). No accent chip, badge color, or special wiki hue (D-02).
