## Spacing Scale

Declared values (multiples of 4; align with Library / Phase 15 baseline):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon–text gaps (`gap-1`), badge padding |
| sm | 8px | Compact gaps (`gap-2`), related-row internal stack |
| md | 16px | Default row padding (`px-4`), panel padding (`p-4`), list gap to panel (`gap-4`) |
| lg | 24px | Section-level gaps if needed (`gap-6`) — prefer `md` inside Library |
| xl | 32px | Avoid in this panel (too sparse for dense Library) |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | Not used this phase |

**Phase-specific spacing (locked):**

| Element | Spec |
|---------|------|
| Library shell | Keep `glass-panel … gap-4 p-5` |
| Source row | Keep `px-4 py-3`; add selection highlight inset (no layout resize) |
| Related panel container | `mt-0` (sibling under list via `gap-4`); `rounded-xl border border-white/10 bg-zinc-950/40 p-4` |
| Related panel max height | `max-h-48` (192px) with `overflow-auto` — independent scroll (D-03) |
| Related row | `px-3 py-2`; `gap-1` between title / kind / snippet |
| Panel header → body | `mb-3` under 「相关文档」 |

**Exceptions:** Selected source-row highlight may use `ring-1` (1px) — not a spacing token. Touch targets for related rows: full row clickable; minimum row height ≈ 44px via `py-2` + three text lines (or two if snippet empty — still OK).

## Typography

Exactly **4 sizes**, **2 weights** (match Library):

| Role | Size | Weight | Line Height | Tailwind / usage |
|------|------|--------|-------------|------------------|
| Heading | 16px | 500 (medium) | 1.25 | `text-base font-medium` — panel title 「相关文档」; Library h2 already this |
| Body | 14px | 400 | 1.5 | `text-sm` — related title, loading/empty/error copy |
| Label | 12px | 500 (medium) | 1.35 | `text-xs font-medium` — kind label (via `sourceKindLabel`) |
| Meta / snippet | 12px | 400 | 1.45 | `text-xs text-zinc-400` — overlap snippet; clamp 2 lines |

**Weights allowed:** 400 (regular) + 500 (medium) only. Do not introduce 600/700 in this panel.

**Truncation:**

- Related title: `truncate` single line
- Kind: no truncate needed (short Chinese labels)
- Snippet: `line-clamp-2`; trust backend ≤160 chars (Phase 15 D-08) — do not re-truncate in FE beyond clamp

## Color

60 / 30 / 10 split using **existing** zinc + cyan tokens (no new CSS variables):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `zinc-950` / `zinc-900/55` glass | App background + Library `glass-panel` surface |
| Secondary (30%) | `zinc-950/40` + `border-white/10` | Stats strip, Cursor card, **related panel** inset, source list border |
| Accent (10%) | Cyan — `cyan-500`, `cyan-400`, `cyan-300`, `cyan-200` | Selection highlight, kind icons, primary buttons (existing) |
| Destructive | `red-300` / `status-badge-err` | Existing source `error` text / failed badge only — **not** related-panel error (related error is muted zinc + optional red tint on message, not a destructive CTA) |

**Accent reserved for (explicit list):**

1. Selected source-row highlight: `bg-cyan-500/15` + `ring-1 ring-cyan-400/30` (same language as `.nav-btn-active`)
2. Optional `data-selected` / `aria-selected` visual only — no second accent color
3. Existing Library chrome (kind icons `text-cyan-300/80`, `btn-primary`) — unchanged

**Related panel text colors:**

| Element | Color |
|---------|-------|
| Panel title | `text-zinc-200` |
| Loading / empty | `text-zinc-500` |
| Error | `text-red-300` (message only; no destructive button) |
| Related title | `text-zinc-100` |
| Kind label | `text-zinc-500` |
| Snippet | `text-zinc-400` |
| Related row hover | `hover:bg-white/5` |

**Never show:** similarity %, RRF scores, affinity bars, score chips (REL-04 / Phase 15 D-09).

**Transparency:** Under `prefers-reduced-transparency`, inherit `.glass-panel` solid fallback; related inset stays `bg-zinc-950/40` or bump to `bg-zinc-950/80` if contrast fails AA on zinc-500 copy.

## Copywriting Contract

All user-visible related-docs strings are **Chinese**, locked by CONTEXT D-10..D-12:

| Element | Copy | Notes |
|---------|------|-------|
| Panel heading | 相关文档 | Always visible when panel mounted |
| Primary CTA | *(none)* — selection is the affordance; related row click = navigate | No new primary button this phase |
| Empty (indexed, zero neighbors) | 暂无相关文档 | D-10; `related-docs-empty` |
| Non-indexed selected | 仅已索引来源可查看相关文档 | D-11; same empty testid; distinguish by text |
| Loading | 加载相关文档… | D-12; ellipsis character `…` (U+2026) |
| Error | 相关文档加载失败 | D-12; optional second line: short `String` detail from IPC, `text-xs text-zinc-500` |
| Destructive confirmation | **N/A** — no destructive actions introduced by related panel | Existing 「移除」 unchanged |

**Kind labels:** Always via `sourceKindLabel(kind)` — e.g. 本地文件, 飞书文档, 笔记页. Do not hardcode ad-hoc kind strings in the panel.

**Accessibility names:**

- Panel region: `aria-label="相关文档"`
- Source row: `aria-selected={selected}` when selected
- Related row: accessible name = title (native text); no score in accessible name

```

├── library-stats
├── header + actions
```

- **Not** a side column; **not** an under-row accordion expand inside each `<li>` (keeps list stable; one shared panel).

## Interaction States

### Source list selection

| State | Behavior | Visual |
|-------|----------|--------|
| None selected | Panel unmounted | Rows idle |
| Click row blank | Select that source; fetch if indexed | Cyan highlight (D-07) |
| Click same row again | Clear selection; hide panel (D-08) | Highlight off |
| Click action button | Handlers only; **no** selection toggle (D-05) | `stopPropagation` on button column |
| Non-indexed selected | Panel shows D-11; **skip IPC** (RESEARCH Pattern 3) | Same cyan highlight |
| Indexed selected | Panel loading → ready / empty / error | — |

### Related panel

| State | `data-testid` | Copy / content |
|-------|---------------|----------------|
| Loading | `related-docs-loading` | 加载相关文档… |
| Empty (indexed, 0) | `related-docs-empty` | 暂无相关文档 |
| Non-indexed | `related-docs-empty` | 仅已索引来源可查看相关文档 |
| Error | `related-docs-error` | 相关文档加载失败 (+ optional detail) |
| Ready | `related-docs-list` + rows | title / kind / snippet only |

### Navigate-on-click (REL-03)

1. Click related row → set `selectedSourceId` to neighbor id  
2. `scrollIntoView` on `source-row-{id}` — `behavior: "smooth"` default; `"auto"` when `useReducedMotion()` (D-14)  
3. Refetch related for new seed (related-chain)  
4. Rapid clicks: **last-wins** via generation counter; ignore stale IPC (D-15)

### Hover / focus

- Related row: `hover:bg-white/5`; keyboard: if row is `<button>` or `tabIndex={0}`, visible `focus-visible:ring-1 focus-visible:ring-cyan-400/40`
- Source row selectable area: `cursor-pointer` on blank content; buttons keep default cursor

## Motion (D-04)

| Motion | Spec |
|--------|------|
| Panel appear | `motion` + `useReducedMotion()` — mirror Library section: `initial={{ opacity: 0, y: 6 }}` → `animate={{ opacity: 1, y: 0 }}`, `transition={{ duration: 0.18 }}` |
| Reduced motion | `initial={false}`; no exit translate; scroll uses `behavior: "auto"` |
| List / rows | No stagger; no continuous animation |
| Scores / graph | Forbidden |

## data-testid Contract (E2E-stable)

| Element | testid | Assert |
|---------|--------|--------|
| Panel root | `related-docs-panel` | Present iff selection |
| Loading | `related-docs-loading` | Text = 加载相关文档… |
| Empty / non-indexed | `related-docs-empty` | Text distinguishes D-10 vs D-11 |
| Error | `related-docs-error` | Contains 相关文档加载失败 |
| List | `related-docs-list` | Present when ready with ≥1 item |
| Related row | `related-docs-row-{sourceId}` | Click navigates |
| Source row | `source-row-{id}` | Select + scroll target |
| Selected marker | `aria-selected="true"` **and** `data-selected="true"` on selected `source-row-*` | Dual signal for E2E |

Existing: keep `source-list`, `library-stats`, per-action ids (`summarize-*`, etc.).

## Accessibility

| Requirement | Spec |
|-------------|------|
| Panel landmark | `role="region"` + `aria-label="相关文档"` on panel root |
| Selection | `aria-selected` on source rows; only one `true` at a time |
| Live region | Loading/empty/error text inside panel is enough; optional `aria-live="polite"` on status node |

| Snippet XSS | React text nodes only — never `dangerouslySetInnerHTML` |
